# Texture sources

- `earth_day.jpg`: NASA Blue Marble Next Generation, August 2004, topography and
  bathymetry (NASA Earth Observatory). Public domain. Derived 4096 × 2048 copy of
  the NASA BMNG image.
- `earth_night.jpg`: NASA Earth Observatory "Earth at Night" 2012, Suomi NPP
  VIIRS / NOAA NGDC. Public domain.

The runtime also generates the atmosphere, starfield and interface graphics
procedurally; no other image assets are used.
